先按输入和科学问题选择路线

结构生物学计算可以分为“得到结构”“分析结构”“研究动态和机制”“设计新分子”四类。计算路线由输入数据、对象和研究目标共同决定。

只有序列

先找已知结构和同源信息，再决定是否预测。得到的是带方法假设与置信度的候选结构，后续分析需要质量检查。

已有三维结构

先确认来源、组装体、链和化学组分，再做比较、界面、口袋、突变、设计、对接或模拟。

已有实验数据

按 cryo-EM、晶体学、NMR、SAXS 等专门路线处理，建立受数据约束的模型或结构集合，并验证拟合与几何。

先回答的问题为什么会改变计算方案
分析对象是什么？蛋白、RNA/DNA、配体、金属、糖链、膜与复合物的处理方式不同
希望回答什么？相似性、局部几何、稳定性、结合、运动与功能对应不同证据
输入来自哪里？实验模型、预测模型、实验原始数据和模拟轨迹需要不同验证
比较条件是否一致？构象、编号、缺失区域、样本环境与原子集合都会影响结果
资源与时间允许多少？轻量统计、GPU 预测和长时集群模拟的调度方式不同

流程一：比较两种结构或突变体——全局相似并不等于口袋相同

研究问题。 “突变体的结合位点是否发生构象变化？”单个 RMSD 很容易误导：如果把整体旋转、缺失残基、不同链或只选到保守片段混在一起，输出一个看似精确的数字没有科学意义。

  1. 输入与身份： 两个坐标文件、目标序列或 UniProt 映射、所需链/装配体、比较范围、实验或预测来源。检查序列差异、截短、缺失残基、不同配体和解析条件；不能因链字母相同就假设同源。
  2. 建立对应： 先做序列或结构对齐，生成“模型 1 残基—模型 2 残基”映射表；明确使用 Cα、主链还是所有重原子。对含多链复合体记录链匹配和可能的对称等价排列；将不匹配或缺失原子排除并报告覆盖率。
  3. 叠合和计算： 用所选匹配原子求最小二乘旋转和平移，再计算同一组对应坐标的 RMSD = √[Σ‖R xᵢ+t−yᵢ‖²/N]；分母 N 是配对原子数。分别报告全局和结合位点局部 RMSD、逐残基位移、对齐长度及覆盖率。若用 US-align/TM-score，说明归一化使用哪个结构长度，避免把不同长度归一化结果直接比较。
  4. 验证与产物： 输出映射表、转换矩阵、叠合坐标、图像及机器可读指标；抽检相同对象与自身叠合应接近 0，分别改变坐标的刚体旋转和平移不应改变结果。对可疑区域观察密度或预测置信度，确认差异不是配体状态、模型缺失或低质量区域引起。

跨复合物界面接触比较。先确认对应组装体、链及残基映射，并定义两结构共同可观测的残基范围；缺失原子、altloc 替代构象与占有率要按预先定义且一致的规则检查。示例可规定排除氢原子与水分子、只比较两个结构均满足原子完整性要求的残基，异链重原子距离 ≤ 4.0 Å 为接触；离子、其他辅因子是否纳入须明示。先保存原子对及距离，再按对应的跨链残基对去重，一对残基即使有多个原子对也只计一次。缺失或部分观测不足的残基对标为“不可比较”，不计为接触消失；对阈值、altloc 和占有率规则做敏感性分析，完整报告剩余覆盖范围。这个阈值是示例，变化的接触数不能直接证明亲和力变化。

软件与适用性。 可使用 US-align 做结构对齐，或 GROMACS 的 gmx confrms（2026.1 文档）比较已对应的原子组；它不会替你保证跨物种同源映射正确。查看二维序列/结构对应和三维叠合可用分子可视化工具。无论选哪一种，都应保存实际二进制版本、参数和选择表达式。

失败示例与处置。 甲结构的位点是作者编号 42A，乙结构在另一编号体系里把 42 当成另一残基；程序仍可能输出小 RMSD。系统应先核对序列和插入码，将映射差异作为未决状态。又如全局叠合得到较小 RMSD 但口袋局部位移较大，应把局部数值与选区展示出来，而非只说“结构相同”。

预测结构的额外限制。 AlphaFold DB 的 pLDDT 反映局部模型置信度，PAE 用于考虑不同区域相对位置的不确定性；高 pLDDT 不能单独证明复合物界面正确，也不能当作突变活性或结合力的实验测量。具体模型可用指标不同，需查其来源。EMBL-EBI AlphaFold DB FAQ。

流程二：cryo-EM 模型重拟合——密度拟合与化学几何同时评估

研究问题。 “现有模型某条环区是否应重新拟合到密度图？”目标不是让某个分数无限提高，而是在实验数据支持的范围内改善模型并保留化学合理性。

  1. 输入： 密度全图、原子模型、序列、分辨率、像素尺寸/坐标框架；如有半图与 mask 一并保存，并确认全图与半图身份。非标准配体需提供可信化学描述与约束文件；核实模型与图在同一坐标系和框内。
  2. 建立基线： 计算并保存全局及逐残基的模型—图拟合、键长角、Ramachandran、rotamer、clashscore 与 CaBLAM 等；记录局部分辨率、异常区域及缺失链，不要只看单一全局平均。
  3. 产生候选： 根据错误类型选择刚体调整、局部修正或实空间精修；每个候选从保留的起点出发，固定输入和参数，保存对应输出模型、日志与版本。phenix.real_space_refine 用全图进行实空间精修，平衡图拟合与几何约束；若二级结构约束错误，可能把错误强行写进模型。Phenix 官方说明。
  4. 独立检查： 用 Phenix 2.0-5817 cryo-EM 验证文档说明的工具复核模型、图与拟合；有半图时，明确其用于哪些验证，比较相应 FSC 曲线，绝不能把用于精修的同一张全图称作独立验证。若要评估过拟合，需要预先设计分离精修与验证数据的流程，而不是精修后反复用验证信号挑候选。
  5. 输出和决策： 给出修改前后逐项差异、局部截图、受影响残基、父子模型和警告。密度支持不足或化学存在多种可能时，保留多解、降低结论强度并交专家审阅；不自动确定离子、配体或修饰身份。

失败示例与处置。 某次精修使全局图相关系数上升，但目标环区出现严重 clash 或 CaBLAM 恶化；应回退或保留供比较，检查是否因权重、分辨率、初始链匹配或错误的二级结构约束造成。密度弱却试图强行拟合配体时，优先标记未解决，而不是从模型输出推断配体已被实验确认。该流程适用于已有图和模型的结构修正；原始电影到三维重构是另一个计算阶段。

NBDB 工具契约示意。 输入必须包含 map_full、model、resolution_angstrom、候选策略及可选 half_maps；输出至少包含 candidate_model、run_manifest、per_residue_validation、comparison。每个文件绑定校验和、软件和参数，失败保留日志。这是产品设计建议，非现有 API。

流程三：小分子结合位姿筛选——得分是候选排序线索

研究问题。 “这些候选小分子是否可能进入已知口袋，哪些值得做进一步实验？”对接给出在特定受体构象、化学准备、搜索空间和评分函数下的位姿与相对评分，不直接证明真实结合或准确亲和力。

  1. 输入： 受体坐标、目标结合口袋来源（共晶配体、实验信息或可靠预测）、小分子结构、明确的互变异构/质子化状态及研究目标。确认受体链、必要辅因子/金属、关键水分子、缺失侧链及适用的化学体系。
  2. 准备： 按研究条件准备受体和配体、生成三维构象与 PDBQT 等软件要求的文件；保存原始化学结构到准备结构的映射，不要静默删除金属、共因子或改变电荷。用已知口袋定义搜索盒的中心和边长，记录坐标系与单位。
  3. 执行： 使用 AutoDock Vina 及相应准备工具，保存评分函数、搜索盒、随机种子、exhaustiveness、线程数、版本和全部输出位姿；针对多个配体微观状态和合理受体构象设计实验时，预先控制计算预算。具体命令随版本和准备工具而变，参照 Vina 官方基础流程（1.2.0 文档）。
  4. 检验： 若有合适共晶结构，保留实验配体作为回对接参照，按正确的原子映射和对称等价方式评估位姿距离，同时确认没有测试集泄漏。查看位姿是否在盒内、是否明显原子碰撞、关键相互作用是否合理；考虑采样重复性及对电荷、受体状态、搜索盒的敏感度。
  5. 输出： 候选、多个可能位姿、评分及其设置、关键接触、失败或未搜索的状态；建议后续独立结合实验或更合适的方法。没有参照位姿时，应声明无法以回对接证明准确性。

失败示例与处置。 搜索盒误设在错误坐标系，程序仍完成并给出得分，但位姿远离真实口袋；预检查要把盒与受体、已知位点可视化并验证覆盖。一个金属酶使用不适用于金属配位的普通打分，低分也可能化学上荒谬；遇到不支持的化学情形须转介专门方法。Vina 官方也指出搜索可能漏掉好的构象：Vina FAQ。

流程四：分子动力学——从轨迹提出动力学假设

研究问题。 “突变是否改变口袋开闭或两个结构域的相对运动？”这要求比较分布与采样，而不只是比较两帧坐标。

  1. 输入： 初始坐标及序列、突变列表、质子化状态、配体/金属参数、力场、水模型、离子条件、温度压力和要度量的坐标或距离。若非标准物质没有可信参数，则暂停或由领域人员补齐，不能随意使用近似参数。
  2. 系统构建： 构造拓扑、溶剂盒和离子；最小化后按预先定义方案平衡，检查温度、压力、密度及明显异常。构建一个或多个独立重复时记录种子、初始条件、平衡长度、生产轨迹长度、步长和硬件/引擎版本。
  3. 模拟： 运行可恢复的长作业，保存拓扑、参数文件、checkpoint、能量和轨迹。对突变体与野生型采用可比较的条件及预算，不能在一个体系采样不足时对均值做强结论。
  4. 处理与指标： 先处理周期边界、使分子完整，再按预定原子组叠合；计算骨架 RMSD、局部 RMSF、口袋体积或域间距离的时间序列和分布。核对原子映射与单位：例如坐标如果由 nm 变为 Å，必须明确换算 1 nm = 10 Å。GROMACS 2024.4 RMSD；周期边界。
  5. 验证与解释： 比较独立重复的分布、不同时间窗口的稳定性、关键接触和采样覆盖，必要时分析自相关与有效样本数；设定统计方法时避免把相邻帧当作相互独立样本。观察到的稳定轨迹并不等于采样已收敛，也不证明真实体系具有相同分布；对功能结论结合突变实验、动力学或其他独立观测。

失败示例与处置。 蛋白跨周期边界看似断裂，直接算 RMSD 会出现巨大跳变；应先按拓扑重建分子并核验轨迹。另一个案例中 100 ns 曲线平稳但多个重复分别停留在不同状态，这不说明全局平衡，应呈现重复之间差异并讨论延长或改进采样，而不是报告单条轨迹均值为确定真值。

流程五：X-ray 晶体学——从衍射数据到模型与验证

目标：给定晶体衍射实验数据和蛋白序列，构建与实验数据、化学几何一致的原子模型。下面是一条常见的分子置换（MR）路线；如果没有合适搜索模型，还可能采用异常散射等实验定相方法。不是所有 X-ray 数据都能通过 MR 求解，也不能只靠反射数据直接读出唯一结构。

1. 先区分输入入口：图像、反射、模型各是什么

可用输入包含的信息从哪里开始
原始衍射图像，如 CBF、HDF5 数据及元数据探测器像素、图像序列及几何/波长/转角等实验信息；需保留完整数据和采集元数据。从峰查找、定指数、积分开始；确认图像头信息、探测器和光束线配置可被读取。
已积分、已标度，可能未合并的反射数据以 Miller 指数 h,k,l 为键的衍射强度 I、标准差及观测元数据，包含每次测量或经合并的统计。识别列、晶胞、对称性和处理状态；未合并数据可以进一步重标度和合并；无法从合并表还原原始图像信息。
已合并反射 MTZ/mmCIF + 序列 + 搜索模型反射表中可能有 I/sigma(I) 或经处理的 F/sigma(F)；模型提供 MR 相位近似。MTZ 只是容器，不意味着已包含相位、R-free 标记或电子密度图。检查数据列、空间群、晶胞、序列与模型身份，再从定相和精修进入；核对已有 free 标记。
反射 + 已有原子模型及原 free 标记可开展受控再精修和验证，但必须确认模型与数据及 free 集对应。保留初始版本做基线；若缺失 free 集或模型曾使用不同集合，标注交叉验证独立性问题。

衍射实验的测量强度与结构因子振幅相关，而相位并未由常规强度直接测得；电子密度重建需要相位信息。MR 使用同源实验结构或预测模型作为搜索模型，确定其在晶胞中的取向和位置，获得初始相位，再通过模型构建及精修改善。初始相位来自搜索模型，因此应关注模型偏倚。

3. R-free、电子密度与配体：具体看什么

  • R-work / R-free：R-work 衡量用于精修的反射与模型预测的一致程度；R-free 使用未参与常规精修的一部分反射作交叉验证。开始建模前应保留已有标记或在规范处理后生成并冻结它，后续所有轮次与候选沿用同一集合。重新随机划分、让 free 数据进入精修或反复以同一 R-free 选大量候选，都会削弱其独立性；相比两个使用不同 free 集的模型，差值不能直接归因于改善。Phenix 文档说明 free 标记的复用与常见错误。
  • 2mFo−DFc 图：常用于观察模型位置与重建密度的吻合；mFo−DFc 差异图提示模型与数据不一致的位置，如缺失或多余原子。它们依赖观测数据、相位及现有模型；地图不是完全独立于模型的“真实照片”。局部比较需统一分辨率范围、图系数及显示水平，必要时采用合适的 omit map 辅助排查偏倚。
  • 局部支持：检查关键残基、侧链和配体在地图中的拟合，结合 RSCC、RSR/RSRZ、配体几何及碰撞，而非只看全局平均。高质量局部密度与合理化学构型共同支持建模；低分辨率或密度不足时，应允许保留不确定或未建模状态。wwPDB X-ray 指南解释局部拟合指标。

图系数生成与实际图网格是两个步骤；在 Coot 中查看需要一致的坐标、晶胞、空间群、相位系数及正确图类型。phenix.refine 手册介绍精修输出及常见地图类型；其默认地图可能包含模型信息，因此不能把可视化中“看见配体”独立地当作结合已证实。

4. NBDB 如何让用户真实执行

平台任务契约：用户选择入口（原始图像 / 反射 / 模型+反射），上传或挂载数据并固定哈希；选择或确认晶体元数据、序列、数据列及搜索模型；设置软件部署、CPU/内存/存储、队列及人工审阅节点。输出关联每一轮反射文件、free 标记、初始/更新模型、日志、图系数、评分与报告。原图体量大，支持分片上传或安全挂载；下载和中间数据应有访问控制。

操作示例而非已运行命令：使用 dials.import 读取用户图像、dials.find_spots 定位斑点，后续依版本使用定指数、积分与标度；从选择好的反射和 MR 模型进入 phenix.refine model.pdb data.mtz 一类运行。真实参数需依据版本、MTZ 列、free 标记及实验设置明确配置；缺失输入或许可证时停止并给出原因。不能把自动管线生成的输出冒充专家确认的最终结构。

验收和异常：运行前校验元数据与数据列；运行后验证所有输出可解析且晶胞/对称一致、free 集一致、日志没有静默跳步；让专家盲审一组有多晶格、低分辨率、配体密度弱、错误空间群或 free 标记不匹配的数据。量化可恢复率、人工干预、关键质量问题漏检率及全流程成本。数据处理统计和结构质量受样本与实验条件影响，预先约定适用范围和基线，而非宣称平台有普适固定通过线。

流程六：蛋白及复合体结构预测——从序列到可检验假设

目标：为给定蛋白序列或多组分体系生成结构候选并理解其可信区域。预测是基于训练和输入信息的模型输出；它可以提供实验设计、搜索模型或候选位点，不是该样品的实验结构，也不自动证明两种分子实际结合。AlphaFold 2 原始论文和 AlphaFold 3 原始论文说明了方法与各自评估范围。

1. 完整数据链：序列 → 特征 → 模型 → 置信度 → 验证

阶段输入、操作、工具与输出验收/容易失败的地方
定义目标FASTA 或结构化任务：每条链序列、名称、拷贝数、物种、截短与构建体边界。多分子模型还需明确非蛋白组分、配体化学身份、修饰及算法支持。校验氨基酸字母、长度、重复拷贝及序列方向；确认异构体、信号肽、剪接形式与实验构建体一致。拷贝数是输入假设，不能由输出自动证明。
准备特征按选定算法和配置进行同源序列检索，生成 MSA；需要时搜索结构模板。复合体可使用链间配对 MSA；保存搜索程序、数据库版本、日期、模板过滤条件与中间特征。查询是否成功、MSA 覆盖/深度、模板与目标关系；低同源、错误配对或跨物种同源关系会影响信息质量。MSA/模板是否必需、是否允许为空与具体算法版本有关，不能把某工具的配置当成所有模型共同要求。
单链或多链接构预测可选择 AlphaFold 2 的单体/Multimer 实现、ColabFold 或符合许可条件的 AlphaFold 3；固定版本、权重、数据库、随机种子、采样数量和 GPU 配置。异步运行，记录作业状态和资源。明确各方法可接受的分子类型及输入限制；检查缺少权重/数据库、显存不足、超时和版本不兼容。不同模型与权重的分数未必直接可比。
产物与排序保留每个候选坐标 PDB/mmCIF、置信度、排序文件、输入/特征摘要和日志；对多 seed/样本保留非首位候选。AlphaFold 2 常见输出见官方仓库；AlphaFold 3 还输出逐样本 mmCIF 与置信度 JSON，见输出说明。验证每个实体、序列、链数量、坐标和分数映射；排名第一仅代表该方法排序最高，不是已被实验证实或最适合某问题的唯一模型。
解释与外部证据可视化逐区域 pLDDT、PAE 矩阵及适用的复合体界面指标；检查构象差异、局部化学合理性及已有实验/同源信息。区分“预测自己的置信度”和“有独立实验支持”；比较多候选并报告分歧。必要时安排交联、突变、结合实验、晶体学或冷冻电镜等独立验证，具体方法取决于研究问题。

单链与复合体的差别：单链预测需要解释各结构域是否可信及其相对方向；复合体还要判断每条链是否正确、界面是否可信、相互位置是否稳定，以及给定的化学计量与分子在生理条件下是否有意义。即使两条链内部都高置信，链间相对取向仍可能不可靠。输入错误的结合伙伴或拷贝数，不能期待算法自动纠正。

2. 置信度分数究竟回答什么

量可以帮助回答不能单独证明
pLDDT估计局部结构可靠性；AlphaFold 2 蛋白常以逐残基值表示，AlphaFold 3 输出可为逐原子值。两条链是否结合、跨域相对排布、热力学稳定性或实验亲和力。低分可能与柔性或无序有关，但也可能是预测误差。
PAE估计以一处为参考对齐时另一处位置的误差，可检查域间/链间相对摆放；矩阵可不对称，需记录行列与链索引映射。真实运动轨迹、实验误差分布或相互作用亲和力；低 PAE 仍是模型自评。
pTM / ipTM 等适用于相应模型的全局/界面相对定位置信度与候选比较；可查具体链对，而不是仅看整体。确证结合、指定动力学行为，或跨模型版本按同一阈值判对错。短链、无序片段和不平衡长度可能影响指标，应结合链对 PAE、局部几何及实验信息。
几何检查发现碰撞、键长/构型异常和不合理配体几何。证明该构象在真实生物体系中存在。

一些坐标文件把 pLDDT 存入 B-factor 字段作为展示约定：它是置信分数，不是实验温度因子。定义及对复合物的解释参考 EMBL-EBI 置信度说明 与 AlphaFold 3 输出定义。具体候选筛选阈值应依据该版本、任务与已验证数据集设定，不能把单一通用阈值当作实验验证。

3. NBDB 落地：把一次预测变成可重复的研究记录

平台需要支持检索现成预测和提交新预测两个入口：先确认数据库条目的序列、物种、版本、覆盖及用户问题是否匹配；否则提交新作业。任务卡保存每条序列的哈希、分子与拷贝数、算法/权重版本、MSA/模板来源及截止时间、seed、计算资源与产物。存储候选、PAE、局部置信及视图，让用户选择目标区域而非只看排名第一的结构。模型更新或数据库变化时，新运行保留旧版本，不覆盖结果。

许可、保密与资源：分别核查软件代码、模型参数、数据库、输出与第三方服务的许可及用户用途；代码开放并不代表权重允许任意用途，例如 AlphaFold 3 官方仓库将源代码和模型参数条款分别列出。若调用公共 MSA 服务会发送用户序列，事先明确服务条款与数据出境/保密要求，必要时使用经授权的本地 MSA 数据库；ColabFold 文档说明其常见运行会查询公共 MSA 服务。提交前检查 GPU、显存、数据库容量、排队与费用，并允许运行中断后查看日志与已生成产物。

验收任务建议：用已知实验结构但避免模板或同源泄漏的保留样本，分别评估正确链身份、覆盖、单体结构误差和复合体界面质量，并按局部信心、MSA 深度、蛋白类别等分层；结构/链映射、对齐区域与指标事先固定。还要测试无可用同源、错拷贝数、长蛋白内存不足、公共服务不可达、权重权限不足和高 pLDDT/高界面 PAE 等情况。报告评测范围、失败和偏差；实验结构本身也可能只代表一种状态，不能用单一参考断言所有不同构象必然错误。

预测可作为上文晶体学 MR 搜索模型：需记录预测来源、裁剪和不确定区域处理，并由衍射数据、模型精修与独立验证逐步检验。模型本身的高置信度并不把最终解自动升级成实验验证。

从文件到科学结论：五条结构计算链怎样真正运行

先建立对象和计算语义，再决定软件、可复现产物与验收方法。下面的数值例子均是说明方法的虚构数据，不是平台已执行的任务。

一个结构分析能否成立，不只取决于算法名称。必须先确定：这个文件代表哪个分子与实验状态；选择了哪个组装体和链；计算定义是什么；输出能支持多强的科学结论。下文以结构比较、预测、对接、电镜精修和分子动力学五条路线说明怎么做。不同路线可复用相同的平台数据模型、产物系统与调度层。

1. 结构对象：把“第 42 个残基”变成可计算对象

一份 mmCIF 同时包含实体、链实例、坐标、实验注释及其编号体系。wwPDB 格式文档 区分 label_asym_id 与 auth_asym_id，也区分 label_seq_id 与 auth_seq_id；链 ID、作者残基编号、序列位置和 UniProt 编号不能默认相同。残基还可能有插入码、构建体删减、未建模区、非标准残基和多个构象。生物学组装体可能需要按文件中的变换矩阵生成，不能直接把晶体不对称单元视为唯一生物学复合物。

  1. 保留原文件及哈希、数据库 ID/版本、实验方法、样品与构建体信息，明确一个文件中的 model 和 assembly。
  2. 为每个实体及链实例建立稳定内部 ID；保存 author 与 label 编号及其对应关系，不用“链 A”当跨文件的唯一身份。
  3. 将参考序列、构建体序列和实际有坐标的残基对齐，输出逐位映射表与无法映射原因。非标准残基、插入码、多重匹配必须显式保留。
  4. 记录候选组装体和不确定性；对称复合物存在多个等价或近似等价链映射时保留候选，按研究问题、序列和几何进行有依据的选择。
  5. 将单位、坐标系、替代构象、占有率、水、配体和原子选择写入计算契约。缺失的坐标标记为未观测，而非隐式补零或当作不存在相互作用。

交付给 Agent 的工具返回：结构元信息、可选择的实体/组装、残基映射表、警告和可追溯文件 ID。用户说“链 A 的 42 位”时，先根据其编号来源解析；多种映射合理时返回候选，明确等待确认。对于链名重命名、残基编号整体偏移、文件的刚体平移和旋转，合理的结论应保持不变；这是非常有价值的变换测试。

2. 两个结构比较：先确定对应关系，再解释 RMSD

研究问题：两个状态的同一个结构域是否改变，界面是否出现不同接触？输入是两个坐标文件、目标生物学组装体及对应实体，而非仅两个文件名。结构域移动、多链对称和缺失区域决定了应该分别比较整体、域内、域间及界面。

  1. 建立映射：先依据实体序列和实验上下文找链，再形成残基对应表；同序列多拷贝要比较候选映射且保存歧义。记录匹配残基数、两边各自长度和覆盖率。
  2. 选择参与叠合的原子：例如共同区域的 Cα；注明是否排除低置信区、柔性环或配体。对应原子对不足或跨不同化学实体时停止。
  3. 拟合与指标：对已给出的对应点求使平方距离和最小的刚体旋转和平移；报告拟合区域与独立评估区域。常用 RMSD = √[(Σ dᵢ²)/N]；它依赖所选原子和覆盖率，少数大偏移对结果影响较大。若距离为 1、2、3 Å，示例 RMSD 是 √(14/3)≈2.16 Å；这只是算术例子。
  4. 补充结构对齐：例如 US-align 可搜索结构对应并报告 RMSD、对齐及以不同长度归一的 TM-score；两种归一化分母不同，必须一并展示。结构对齐的对应关系可能与序列/人工指定的功能对应不同，应保留两者并解释。US-align 方法与指标说明
  5. 局部和界面：在每个结构内部用明确原子规则计算残基间接触、界面面积或氢键，再通过映射比较；报告未观测区域，不能将缺失坐标解释为接触消失。分辨率、构象、样品和化学状态差异也可能改变观察。

可验收输出：原子/残基映射 CSV、叠合变换、选择表达式、两种归一化得分、局部位移和接触差异表、可视化脚本与证据报告。对照测试：刚体变换应不改变拟合后的 RMSD；改变选择区应明确改变统计对象；删除一段坐标应产生“无法比较”而不是伪造负结果。将模型的自然语言描述与从表格重新计算的数字独立比对。

3. 结构预测：坐标、置信度和参考证据一起阅读

  1. 定义预测对象：全长、截短构建体、复合物组分、配体和环境不同，对应不同科学问题。检查已知实验结构与同源模板，避免重复预测掩盖更直接的数据。
  2. 输入与版本：记录序列和组分、模型代码与权重、MSA/模板数据库快照、采样设置、随机种子及硬件环境。验证泄漏时，对模板及数据库建立时间截止，研究预测当时实际能访问的信息。
  3. 读模型输出：对支持这些指标的预测模型，pLDDT 是残基局部置信度，PAE 描述在某残基对齐参考下另一残基位置的预测误差；高局部置信度并不自动保证两个结构域的相对排布或复合物界面可靠。AlphaFold DB 对 pLDDT 与 PAE 的解释
  4. 外部核查：覆盖率、构建体与参考序列的对应、局部几何、结合位点的实验证据，以及不同预测间的可解释差异。预测结构可供提出假设；亲和力、功能及分子状态变化需要对应的实验或经过验证的专门方法。
  5. 输出：候选坐标、模型版本、局部及成对置信度、模板/MSA 信息、缺失和可疑区域、依据来源。对用户的问题给出结论强度：已由数据支持、预测提示、或无法判断。

可发表问题示例：研究 Agent 能否在预测模型存在高局部置信度但相对构象不确定时，正确选用 PAE、停止推断并请求实验数据。构建家族分离的题集，对照只有坐标的 Agent、提供置信度的 Agent、加入显式领域规则的 Agent；主要终点预先定义为正确识别结论边界的比例，并记录拒答质量、误拒和证据引用正确率。

4. 小分子对接：姿势搜索与生物活性证明之间的距离

  1. 检查受体构象、结合位点来源、缺失片段、质子化状态、金属/水/辅因子及受体准备；配体需明确化学身份、立体异构、质子化和所用参数。对化学状态不确定的体系，列出候选并分开计算。
  2. 规定搜索空间：已知口袋、来自实验的约束或全局搜索；固定搜索预算、随机种子与评分函数版本。公开工具的适用范围和许可证需按部署版本核对。
  3. 生成多个姿势后检查原子碰撞、相互作用几何、关键官能团朝向和重复运行稳定性；对有参考晶体姿势的测试集，可计算明确对称性处理的重对接 RMSD，也需测试不同配体与不同蛋白状态。
  4. 对接打分属于模型化排序信号，受受体构象、溶剂与评分假设影响。不要把它直接当实测结合自由能、Ki 或验证药效；输出可能姿势、分数、结构警告与后续实验建议，并保留未进入首选的候选。

研究对照：把“自动选择最佳分数”与“同时进行姿势几何、输入状态及不确定性检查”的系统比较。对每个目标做时间或化学骨架分组，避免类似配体同时进入开发与测试；若最终目标为活性排序，使用独立测定数据，并将无结果、不可参数化和超时保留在分母及失败分析中。

5. 冷冻电镜精修：如何避免只优化一张漂亮的图

输入包括起始模型、序列、全图、能获得时的两个 half-map、像素大小/坐标框架和样品信息。先保留起始版本，并用同一套评估规则记录模型—图的一致性、化学几何、离群与局部问题。一个常见精修目标同时考虑地图拟合与化学约束；约束过弱可能追逐噪声，过强可能掩盖真实构象差异。

  1. 确认数据匹配：map 与模型的坐标原点、像素大小、盒子和对称性；识别缺失配体、离子及字典。错误的坐标框架可造成整体拟合差或误判。
  2. 生成候选：按问题类型选择刚体、局部优化、侧链修正或其他允许的操作，并记录参数、限制、运行环境及开始前的基线。Phenix real-space refinement 官方文档说明该操作使用全图；具体验证协议和数据使用必须按选定工具核查，不能假定所有程序都以 half-map 做精修。
  3. 独立验证：对候选和初始模型使用相同规则重新计算全局及局部的图—模型拟合、几何、键长角、Ramachandran/rotamer 离群和碰撞；按预先确定的容差与优先级比较，并标记局部改善是否伴随别处劣化。
  4. 理解两类 FSC：独立半数据重建得到的 half-map FSC 用于评价地图分辨率；模型与图的 FSC 是另一类比较。针对模型过拟合，可设计严格的工作图/验证图交叉验证：确保验证数据未参与候选拟合、选择和调参，并针对模型偏差按已发表方法操作；仅仅提供两张 half-map 不自动构成独立验证。half-map 过拟合研究；模型对 half-map 交叉验证研究。
  5. 候选决策：拒绝违反硬约束的模型；在允许范围内报告多指标及局部证据，保留起始模型和不确定位置。若实验图不能区分多个构象，应如实给出多解，不让模型用高全局分数消除不确定性。

科学意义：half-map 的独立重建可缓解某些噪声过拟合，仍可能受到两半共同系统误差或处理过程影响。更好的研究需要配合几何、局部密度、专家盲审与独立数据；“分辨率更高”或“图—模型相关更高”都不单独证明每个原子正确。

6. 分子动力学：轨迹存在不等于采样充分

  1. 定义问题和体系：要研究稳定性、构象分布、相互作用持续时间，还是相对自由能？选择相应模型、实验条件、状态和适当方法；固定构建体、配体参数、质子化与力场，并检查拓扑与坐标匹配。
  2. 准备：建模缺失部分时记录假设，定义水、离子、盒子和周期边界；能量最小化并按所用力场与方法进行温度、压力平衡。记录工具版本、模拟参数、约束和单位。
  3. 生产与重复：设定时间步长、积分器、恒温/恒压策略、截断及长程处理，执行独立重复；保存随机种子、能量、轨迹、checkpoint 和实际完成步数。长任务需要能以原外部作业 ID 对账并恢复。
  4. 轨迹分析：确认周期边界与分子完整性，使用相同的参考与原子选择计算 RMSD、RMSF、构象分布、接触随时间变化等。输出每条重复和不确定性，不用逐帧当作独立样本；时间相关性会减少有效样本数。GROMACS 手册
  5. 解释：对关键观测检查不同重复、初始构象与采样长度的稳定性；RMSD 平稳不证明稀有事件、自由能或全局平衡已经收敛。必要时采用适合问题的增强采样与独立验证，报告时间尺度和力场局限。

任务契约示意：simulate(topology_id, coordinates_id, forcefield_version, conditions, seed, requested_steps) → job_id → trajectory_id + logs + checkpoint；验证器检查拓扑与坐标、实际执行步数、能量异常、分析选择和输出可读性。以同一预算比较自动与人工配置时，必须同样记录失败、等待、计算成本及科学任务正确率。

7. 从五条路线提炼平台能力与论文假设

共同的数据对象是样品/实体—组装体—链实例—残基映射—实验或预测数据—运行—产物—验证。每个 Operation 有类型、单位、前提和结果契约；不同科学路线增添专属对象，例如电镜 half-map 与 mask、分子动力学拓扑与轨迹、对接的化学状态和受体构象。系统能按前提判断是否继续，并在不确定时提出可执行的补充信息请求。

一个可研究的假设是：结构语义约束与独立结果验证，能否降低 Agent 在链重命名、缺失坐标、预测不确定性和输入不匹配场景下的科学错误率？对照应至少包含同模型同工具的基础 Agent、仅格式/schema 检查、加结构语义检查、加独立验证的完整系统；固定工具、可访问数据与计算预算。按结构家族和来源划分，报告完整任务的正确率、错误结论率、合理拒答、证据重算通过率、人工时间与计算成本。研究数据和任务/评分脚本尽可能公开，必要时结合专家盲审。

以上研究路线是本报告提出的假设与实验设计，尚未在 NBDB 上完成实现或证明优势；实际计算前需确认软件许可、版本、数据适用性与运行环境。工具目录仍可用于查看可接入的软件与各自的参考链接。
