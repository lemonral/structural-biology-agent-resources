不同结构任务
需要不同的科学判据

共用任务与执行协议，按任务加载输入类型、前置条件和验收规则。

本章设计判断

“通用”来自共享协议和可扩展工具操作；科学正确性仍由各类任务的领域规则保证。以下是概念工作流，不是已经部署或可直接提交的配置。

ROUTE 01

序列到结构

输入 → 操作 → 产物 → 科学验收

INPUT / 必要输入蛋白/核酸序列；必要的组分与研究条件
OUTPUT / 交付产物结构候选、预测置信度与几何检查摘要

科学检查：先检查输入身份和模型适用范围；预测置信度不能直接证明实验构象或功能。

工具入口：MMseqs2 · HH-suite · ColabFold · AlphaFold 3 · MolProbity

展开完整路线与关联阅读

序列校验 → 同源/结构检索 → 输入准备 → 模型预测 → 置信度/几何检查 → 设计与候选筛选

科学工具与研究平台Biomni ↗通用能力先来自科学环境，再由代码组合结构计算与专用环境Speak to a Protein ↗让对话、三维选择与计算共享结构场景
ROUTE 02

结构比较

输入 → 操作 → 产物 → 科学验收

INPUT / 必要输入两个或多个结构；组装、链与残基选择
OUTPUT / 交付产物可追溯残基映射、叠合结果、局部或整体差异

科学检查：必须记录比较对象、映射、原子选择和叠合范围；全局 RMSD 不能单独解释多结构域运动。

工具入口：US-align · Foldseek · Gemmi · PyMOL

展开完整路线与关联阅读

身份/构象/组装检查 → 残基映射 → 选择与叠合 → 几何/界面分析 → 独立检查 → 报告

评测、失效与研究综述ProteinGeoBench ↗把结构查询与坐标计算分开评测结构计算与专用环境Speak to a Protein ↗让对话、三维选择与计算共享结构场景
ROUTE 03

结合姿势研究

输入 → 操作 → 产物 → 科学验收

INPUT / 必要输入受体与配体/结合伙伴；状态与约束
OUTPUT / 交付产物候选姿势、聚类、相互作用与对照检查

科学检查：评分不是实测亲和力；质子化、构象与搜索范围影响解释，应检验合理性和对照。

工具入口：AutoDock Vina · GNINA · HADDOCK3 · PLIP

展开完整路线与关联阅读

组分检查 → 受体/配体状态 → 搜索与约束 → 对接 → 聚类/相互作用 → 对照验证

科学工具与研究平台SciToolAgent ↗用工具关系图缩小多步规划的搜索空间结构计算与专用环境ProteinMCP ↗服务层封装工具，技能层组织计算任务
ROUTE 04

动力学与自由能

输入 → 操作 → 产物 → 科学验收

INPUT / 必要输入结构体系、物理条件、参数模型与采样目标
OUTPUT / 交付产物轨迹、统计量、收敛与不确定性分析

科学检查：作业正常结束不证明采样充分；区分平衡、生产采样、统计独立性和误差估计。

工具入口：GROMACS · OpenMM · MDAnalysis · alchemlyb

展开完整路线与关联阅读

体系参数化 → 最小化/平衡 → 生产/增强采样 → 轨迹处理 → 统计/自由能 → 收敛/误差

评测、失效与研究综述SciAgentGym ↗分开测单步工具与多步流程，定位链路断点结构计算与专用环境Agent Rosetta ↗为复杂软件建立动作、文档与反馈环境
ROUTE 05

cryo-EM

输入 → 操作 → 产物 → 科学验收

INPUT / 必要输入显微数据或已重建密度图；模型与元数据
OUTPUT / 交付产物重建/候选模型、图质量与几何验证
两个入口：原始显微数据从预处理和重建开始；已有密度图先核对质量与元数据，再进入建模、精修和验证。

科学检查：图拟合与模型几何要分开检查；局部分辨率、过拟合和候选回退不能由单一总分代替。

工具入口：RELION · CryoSPARC · ModelAngelo · Phenix · Coot

展开完整路线与关联阅读

运动/CTF → 挑选/分类 → 重建/精修 → 图质量 → 建模/精修 → 图与几何验证

结构计算与专用环境StructAgent ↗推理和执行分工，模型修改保持可追踪结构计算与专用环境Structural Refinement ↗总分改善时，仍要追查局部退化
ROUTE 06

晶体学

输入 → 操作 → 产物 → 科学验收

INPUT / 必要输入衍射数据、实验信息与必要先验
OUTPUT / 交付产物模型、精修记录、R-free 与局部验证

科学检查：保留独立测试集和数据处理记录；数据质量、模型偏差与局部几何需同时检查。

工具入口：DIALS · XDS · CCP4 · Phenix · Coot

展开完整路线与关联阅读

索引/积分/尺度化 → 数据质量 → 定相/置换 → 模型构建 → 精修 → R-free与局部验证

结构计算与专用环境Structural Refinement ↗总分改善时，仍要追查局部退化科学工具与研究平台Paper2Agent ↗把论文代码变为经过测试的方法接口
ROUTE 07

NMR

输入 → 操作 → 产物 → 科学验收

INPUT / 必要输入谱数据、归属与实验约束
OUTPUT / 交付产物结构集合、约束符合度与独立验证

科学检查：追踪归属和约束来源；结构集合反映信息与建模条件，不能只展示一个最优构象。

工具入口：NMRPipe · CcpNmr Analysis / CCPN · CYANA · Xplor-NIH

展开完整路线与关联阅读

谱处理 → 归属 → 约束 → 结构计算 → 集合分析 → 独立验证

科学工具与研究平台Biomni ↗通用能力先来自科学环境，再由代码组合科学工具与研究平台ToolUniverse ↗把科学工具整理成可发现、可调用的接口层

SAXS / 整合建模

输入 → 操作 → 产物 → 科学验收

INPUT / 必要输入散射数据、多源约束与表示假设

科学检查：拟合良好可能存在多个解释；显式报告多解性、先验与独立证据。

工具入口：ATSAS · IMP

展开完整路线与关联阅读

02 / TOOL DIRECTORY

先按输入与任务选类，再展开具体工具

69 项工具保留原有输入、输出、验证和来源。这里按 16 类折叠展示；“列入目录”与“已在目标服务器部署验证”分开理解。

序列与多序列比对5 项 · MMseqs2 / HH-suite / MAFFT / HMMER

MMseqs2 命令行

大规模同源检索、序列聚类与预测所需的同源序列准备。

输入蛋白/核酸 FASTA、目标数据库及检索参数。
输出比对命中表、聚类成员/代表序列；相关工作流可生成比对数据。
科学检查核查覆盖度、相似性、数据库版本和聚类阈值；保留低复杂度过滤设置。
资源、边界与官方来源

多核 CPU；部分模块支持 GPU；大数据库需要独立存储与索引。

命中不直接等于同一功能；不同阈值会改变同源集合。数据库、索引和 GPU 支持按具体版本配置。

工具官方来源 ↗

HH-suite 命令行

利用序列谱/隐马尔可夫模型检索远缘同源与结构模板。

输入蛋白序列、A3M 多序列比对、目标谱数据库。
输出HHblits 迭代比对、HHsearch 模板命中与统计分数。
科学检查检查比对覆盖、插入缺失、低复杂区和模板日期，记录数据库快照。
资源、边界与官方来源

多核 CPU；谱数据库占较大存储与内存。

远缘同源匹配需要结合结构与生物学背景解释；本工具不是结构预测模型本身。

工具官方来源 ↗

MAFFT 命令行；在线服务另计

为蛋白/核酸序列生成多序列比对。

输入FASTA 序列集合。
输出对齐后的 FASTA 等序列比对。
科学检查检查长度异常、缺口分布、关键位点与同源性；保存选择的算法。
资源、边界与官方来源

CPU；不同算法的时间和内存需求差异明显。

准确与快速模式适用规模不同；不能用比对本身证明同源或功能。使用本地软件与调用公共服务的条件不同。

工具官方来源 ↗

HMMER 命令行；EBI 在线服务另计

构建和检索序列谱，定位蛋白家族/结构域并搜索同源序列。

输入序列、多序列比对、谱 HMM 或谱数据库。
输出结构域匹配、命中显著性、对齐结果。
科学检查核对域边界、E 值和覆盖度；记录使用的家族数据库版本。
资源、边界与官方来源

CPU；批量数据库检索可放入队列。

谱匹配属于统计证据；多个重复结构域、低复杂区和错误模型会影响解释。

工具官方来源 ↗

SeqKit 命令行

对 FASTA/FASTQ 做校验、统计、筛选、去重和批量拆分。

输入FASTA/FASTQ 与筛选条件。
输出清洗后的序列、统计表、子集文件。
科学检查确认字母表、序列 ID 唯一性、长度、重复项和原始/输出条数。
资源、边界与官方来源

CPU；适合流式处理，按输入规模规划磁盘。

这是数据准备工具，不负责同源性推断、蛋白折叠或结构质量评价。

工具官方来源 ↗
结构检索与比较4 项 · Foldseek / US-align / DSSP / FreeSASA

Foldseek 命令行；官方在线服务另计

对蛋白三维结构进行快速数据库检索、结构比对与聚类。

输入PDB/mmCIF 结构或预建结构数据库。
输出结构相似命中、比对、统计量与聚类结果。
科学检查同时看结构覆盖、比对长度、TM 分数/显著性和低置信区；保留结构库版本。
资源、边界与官方来源

多核 CPU；部分工作流/版本可用 GPU；大库需要索引。

局部相似不等于全长功能相同；检索数据库与预测结构误差会影响结论。

工具官方来源 ↗

US-align 命令行；作者网页

对蛋白、RNA、DNA 及复合物做统一结构叠合比较。

输入两份结构坐标；链选择/映射等参数。
输出TM-score、RMSD、残基/链匹配和叠合坐标。
科学检查报告归一化方式、匹配长度、链对应和结构域选择，避免只报告一个 RMSD。
资源、边界与官方来源

CPU；批量两两比较可并行。

比较依赖正确的生物学组装体与链匹配；刚性整体叠合可能掩盖结构域运动。

工具官方来源 ↗

DSSP 命令行；网页服务

根据已有三维坐标分配蛋白二级结构与相关几何注释。

输入PDB/mmCIF 蛋白结构。
输出逐残基二级结构、氢键与可及性等注释，取决于版本/输出模式。
科学检查检查链断裂、缺失主链原子和残基编号；保留原始坐标到注释的映射。
资源、边界与官方来源

CPU。

DSSP 是从坐标赋值二级结构，不是从序列预测二级结构；缺失或低可信坐标会影响结果。

工具官方来源 ↗

FreeSASA 命令行；Python/C 接口

计算溶剂可及表面积，辅助暴露度、埋藏面积和界面分析。

输入PDB 结构或坐标/原子半径；探针及原子选择。
输出整体、逐链、逐残基或逐原子的 SASA。
科学检查明确探针半径、氢原子/配体处理和半径集合；界面面积使用一致的组装体与链组合。
资源、边界与官方来源

CPU。

SASA 取决于参数和结构状态；埋藏面积不能直接替代结合自由能。

工具官方来源 ↗
结构预测5 项 · AlphaFold 3 / ColabFold / Boltz-2 / Chai-1

AlphaFold 3 本地命令行；官方托管服务是独立使用方式

预测蛋白、核酸、小分子等组成的生物分子结构与相互作用构象。

输入实体与化学描述的 JSON、序列；可指定比对、模板和约束信息，依版本而定。
输出mmCIF 预测结构、置信度与排序等结果文件。
科学检查检查 pLDDT、PAE、pTM/ipTM 等适用指标、链计量比、立体化学与已知实验；多种子比较。
资源、边界与官方来源

GPU 推理；比对/模板数据准备可用 CPU；较大的序列与模板数据库。

源码许可与模型参数/输出条款不同；开放参数需按官方流程授权，受非商业等条件限制。高置信预测不证明结合、活性或生理状态。

工具官方来源 ↗

ColabFold 命令行；Notebook；公共比对服务可选

以 MMseqs2 比对和 AlphaFold 系列模型进行易用的单体/复合物预测。

输入FASTA/CSV/A3M；模板与运行配置。
输出结构、逐残基置信度、PAE 等报告和排序结果。
科学检查记录模型、种子、比对来源/数据库时间；检查复合物计量比、PAE、界面可信度。
资源、边界与官方来源

GPU 推理；本地比对需要 CPU/数据库，部分版本支持 GPU 搜索。

公共 MSA 服务要求按其规则使用，不能假定无限并发或隐私承诺；生产规模宜使用合适的独立比对后端。模型权重和依赖分别检查许可。

工具官方来源 ↗

Boltz-2 命令行；Python 包

联合预测生物分子复合物结构；支持其定义范围内的配体结合亲和性预测。

输入描述蛋白、核酸、配体与预测属性的 YAML；比对/模板可选。
输出结构、置信度文件；指定任务时输出结合分类概率/亲和性预测。
科学检查核对结构可信度、化学有效性和靶标/配体适用性；亲和性输出的单位和字段定义必须保留。
资源、边界与官方来源

主要为 GPU；CPU 可运行但慢；自动 MSA 服务或本地比对。

官方代码和权重标为 MIT；仍需管理外部比对服务与依赖。模型分数不等于实验 Kd，亲和性指标不能与 FEP 或不同实验终点直接混为一谈。

工具官方来源 ↗

Chai-1 命令行；Python 接口

对蛋白、小分子、DNA/RNA 等分子体系进行结构预测。

输入实体类型标记的 FASTA/化学描述，及可选比对、模板或约束。
输出mmCIF 结构、置信度和预测结果目录。
科学检查检查实体解释、构象、化学几何和置信度；保留可选约束与模板来源。
资源、边界与官方来源

Linux 和具备相应 CUDA/bfloat16 支持的 GPU；按体系规模规划显存。

代码和权重官方标为 Apache-2.0。大复合物资源需求高，支持多种分子类型不等于对所有修饰/状态都已验证。

工具官方来源 ↗

ESMFold 命令行；Python 接口

从单条蛋白序列快速得到结构，作为无需显式 MSA 的预测基线。

输入蛋白 FASTA。
输出PDB 结构和模型置信信息。
科学检查检查长度、pLDDT、低复杂/无序区，并与其他模型或实验交叉核验。
资源、边界与官方来源

GPU 常用；长序列需要显存管理，可分块/卸载。

原 facebookresearch/esm 仓库已于 2024-08-01 归档；部署须锁定兼容依赖。不是通用蛋白-核酸-配体复合物预测器。

工具官方来源 ↗
蛋白设计与改造4 项 · RFdiffusion / ProteinMPNN / LigandMPNN / Rosetta / PyRosetta

RFdiffusion 命令行；Python 工作流

在长度、结构片段、热点或对称性条件下生成蛋白骨架。

输入目标/功能片段结构、contig 规格、设计条件与模型配置。
输出候选骨架 PDB、轨迹及映射信息。
科学检查骨架生成后需序列设计、独立回折预测、几何/界面过滤及实验验证。
资源、边界与官方来源

GPU；常需大量候选采样，可使用作业数组。

生成骨架不等于得到可表达、可结合或有功能的蛋白；目标截取和固定残基映射会影响设计。模型、代码、后续依赖各自核查许可。

工具官方来源 ↗

ProteinMPNN 命令行；Python

依据给定蛋白骨架设计氨基酸序列，可固定部分位置/链并设置约束。

输入蛋白 PDB 或解析后的骨架数据、固定位置/设计链配置。
输出候选 FASTA 序列、序列得分及采样信息。
科学检查核对编号与固定位置，做回折一致性、序列多样性、聚集/表达与功能筛选。
