把阅读转成平台开发

  1. 用 ReAct 建立最小闭环：从用户问题到工具请求、实际结果、下一步与最终产物，每一步都记录状态。
  2. 用 TaskMatrix.AI、ToolLLM 和 Biomni 设计工具目录：区分软件、操作、输入输出、环境、适用范围与当前可用部署。
  3. 用 Paper2Agent 研究一个现有开源分析工具的接入：提取接口、固定环境、生成包装、添加真实样本测试，再登记操作。
  4. 用 LLMCompiler 构造带依赖的分析图：先检查输入，再并行运行独立工具，最后汇总；长任务另加持久化、取消与恢复。
  5. 用 Reflexion、AutoGen 和 Virtual Lab 划分职责：规划、执行、科学校验、报告各自有明确产物，失败修复有预算与终止条件。
  6. 用 PaperQA2 为分析报告增加证据：每项引用可定位来源，将文献陈述、计算观察和解释假说分开记录。
  7. 用 ToolSandbox、τ-bench、ScienceAgentBench 与 PaperBench 设计验收：输入/状态正确、工具真实运行、产物完整、数值与解释合理、重复运行稳定。
阅读时不要把不同成功标准混在一起：能生成代码、能调用接口、能完成作业、能得到正确数值、能支持科学结论，是不同层次。论文中的演示范围和版本也是方法理解的一部分。
