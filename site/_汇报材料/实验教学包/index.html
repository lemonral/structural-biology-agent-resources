TaskSpec、真实科学工具与可复查的交付

本包没有语言模型、API请求或凭证。它用固定计划展示执行、检查、记录和评分的实现。4项真实坐标操作、12项边界及故障fixture不构成Agent性能评测；所有任务来自同一AdK对象家族，不能证明跨对象泛化。

python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run_lab.py --output runs/my_first_run

已测Python 3.12.1、NumPy 1.26.2、Biopython 1.81。requirements.txt按已测依赖固定版本，没有模型SDK。以上激活命令适用于macOS/Linux；Windows请使用对应虚拟环境激活命令。部分平台安装旧版Biopython可能需要编译工具，环境准备成功后再运行计算。使用新的输出目录，以免覆盖运行证据。软件版本也记录于execution_evidence.json。坐标文件已冻结在assets，无需联网。统计脚本生成的是明确标为SIMULATED的抽象教学数据。

实际科学操作

RMSD任务固定首个模型、auth链A和214对标准氨基酸Cα，排除异源配体和水，不作离群剔除。分区取MDAnalysis腺苷酸激酶示例。全链独立拟合7.130700Å；各区独立拟合CORE1.975054Å、NMP1.576049Å、LID0.470656Å。CORE参考对齐后，NMP11.232016Å、LID15.581193Å。两份静态晶体模型不能单独提供运动路径、速率或配体因果解释。

接触任务使用1AKE链A蛋白重原子与同链AP5配体的57个重原子，欧氏距离≤4Å定义几何接触。得到34个接触残基、234个原子对，另用原子表和标量距离复核。几何接触不等于亲和力、氢键或因果功能。

状态与故障fixture

  • 缺少链选择返回NEEDS_INPUT。不存在的链、缺输入、此能力不支持的nm单位返回REJECTED。nm是合法物理单位，拒绝只是本能力边界。
  • 错误对象、错误数值、错误输出单位是人为修改产物的负例，检查器阻断交付。
  • 重复结果投递复用相同产物身份，不再次计算。模拟超时没有真实等待或外部超时。
  • 提交确认丢失、外部作业匹配和取消均是明确模拟。唯一匹配才继续，无法核对保持UNKNOWN，取消未获确认保持CANCEL_REQUESTED。

一份运行会保存什么

runs/my_first_run/global/
  task.json             已冻结任务
  plan.json             固定计划版本
  objects.json          坐标摘要与auth链身份
  result.json           映射、变换和数值
  validation.json       检查版本、错误与容差
  events.jsonl          追加事件，含Attempt身份
  run.json              最终状态和全部工具尝试

产物content_id取规范化JSON的内容摘要，输入坐标SHA256取原始字节，两者不能混用。重试是同一独立run中的新Attempt，不新增评测分母。缺run、缺产物、损坏产物仍保留预分配评分行和失败分母。全局参考输入破坏或缺失答案键写INVALID_EVALUATION并终止，不能记为模型失败。成本缺记录单列覆盖数，不把未知成本伪装成零成本。

接入真实模型与成熟部署前

将FixedPlanner替换为实现Planner.propose(TaskSpec,observations)的适配器。模型只能提出注册工具和类型化参数，compile_plan及科学验收保持程序执行。这个教学编译器只接受两个固定管道，若支持一般DAG需另实现类型与前提检查、分支和有界修订，并在冻结任务集验证。实际模型比较还要保存模型版本、采样设置、提示、上下文、全部费用和失败。

服务化还需持久数据库、原子任务领取、外部Job身份、权限与路径隔离、资源配额、真实取消确认和发布回归。本包的内存控制与文件事件不提供数据库事务、断电持久性或分布式exactly-once保证。
