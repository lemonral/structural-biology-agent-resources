A practical implementation order

  • Read the English PRD to identify P0 requirements and fixed contract IDs.
  • Build one deterministic real-input path and independent checks.
  • Add durable identities, immutable artifacts, state and budget transactions.
  • Connect one real-model planner through a deterministic compiler.
  • Exercise ambiguity, invalid inputs, permission denial, unknown execution, cancellation and restart.
  • Freeze candidate versions and evaluate scientifically valid delivery, hidden errors, intervention and complete cost.

Deterministic exercises and design templates

The durable-execution exercise uses separate local SQLite ledgers to simulate the control service and an external scheduler. Close and reopen connections after a lost acknowledgment, reconcile the original job and distinguish completed execution from scientific rejection. It demonstrates persistence and failure handling, not production HPC integration.
