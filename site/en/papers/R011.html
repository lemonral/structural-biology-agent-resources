AutoGen

AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation

First public: 2023-08-16 · Conference publication · COLM 2024 · Main conference

AutoGen packages model responses, tool execution and human participation as conversable roles with programmable message interactions. It is a collaboration framework rather than one fixed solver algorithm.

Research problemMechanismEvidenceLimitsImplementationReproductionReading connectionsSources

Research problem

Applications require different mixtures of model calls, code execution, retrieval and human decisions; a reusable abstraction must express these control flows.

How the mechanism works

  1. Conversable agents expose common send, receive and response interfaces; a role need not own a separate model.
  2. Automatic replies, triggers and termination rules express two-role, hierarchical or group conversations. Messages can carry code and execution observations as well as prose.
  3. Executor and retrieval roles return real feedback, while the developer retains responsibility for permissions, history retention and human escalation.

Study setting and reported evidence

Six application families demonstrate different interaction patterns. Some include quantitative baselines, while others mainly show expressiveness. Their task-specific outcomes cannot be pooled into evidence that multi-agent systems are universally superior.

Limits and interpretation

Framework expressiveness differs from algorithmic benefit. Conversation history is not automatically durable state, external-job reconciliation or duplicate-side-effect protection.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Separate planning, execution and review only where responsibilities and artifacts can be isolated. Store structural files, job state and validation results independently rather than transmitting scientific facts as conversational claims.

Reproduction and implementation checks

Pin the paper's implementation separately from current SDK versions. Match tools and budget against a simpler controller and inspect actual executor outputs, stopping rules and human interventions.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.

Compare mechanisms

MetaGPT encodes software-team operating procedures as role responsibilities, structured artifacts and handoff rules. The central idea is disciplined coordination rather than intelligence gained merely by increasing the number of roles.

Complementary perspective

R027 · MAST

MAST derives a taxonomy of multi-agent failures from execution traces and supplies annotations and an automatic labeling workflow. It is a diagnostic resource rather than an agent that automatically repairs every failure.
