Plan and Solve

Plan-and-Solve Prompting: Improving Zero-Shot Chain-of-Thought Reasoning by Large Language Models

First public: 2023-05-06 · Conference publication · ACL 2023 · Long Papers

Plan-and-Solve prompts a model to formulate a decomposition before solving a zero-shot reasoning problem. PS+ adds attention to variables, operations and intermediate results, still entirely within language generation.

Research problemMechanismEvidenceLimitsImplementationReproductionReading connectionsSources

Research problem

Zero-shot CoT can miss steps or misinterpret problem semantics. The paper distinguishes such failures from calculation errors and tests a more explicit planning instruction.

How the mechanism works

  1. Analyze error categories instead of treating every wrong answer as the same reasoning failure.
  2. First ask for a plan and subtask decomposition, then continue with the solution. Here 'execution' means generated solution text, not running a workflow.
  3. PS+ makes relevant quantities and calculation details more explicit, allowing decomposition and detailed solving to be compared.

Study setting and reported evidence

Ten reasoning datasets, including GSM8K, SVAMP, StrategyQA and symbolic tasks, use the paper's GPT-3 configuration. Final-answer accuracy improves over tested zero-shot baselines and approaches few-shot CoT in some arithmetic settings.

Limits and interpretation

A complete-looking plan may still solve the wrong problem. Answer accuracy does not validate typed parameters, files, dependencies, resource limits or recovery.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

List identity checks, comparison scope and required artifacts before structural analysis. A written plan acquires execution meaning only after steps map to concrete tools, input/output conditions and acceptance rules.

Reproduction and implementation checks

Freeze model, datasets, extraction rules and decoding. Compare PS, PS+, zero-shot CoT and few-shot demonstrations separately; do not attribute tool orchestration guarantees to a language-only experiment.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.

Compare mechanisms

R001 · CoT

Chain-of-thought (CoT) prompting places a question, intermediate natural-language steps and an answer in each few-shot demonstration. It studies reasoning prompts rather than an agent that executes tools.

Complementary perspective

R007 · ReWOO

ReWOO separates planning, tool execution and synthesis. Evidence variables express dependencies before actual tool returns fill them, reducing repeated prompt construction rather than eliminating observation use.
