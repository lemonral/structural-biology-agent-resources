Voyager

Voyager: An Open-Ended Embodied Agent with Large Language Models

First public: 2023-05-25 · Journal publication · TMLR 2024

Voyager accumulates executable skills through an automatic curriculum, feedback-driven code revision and a skill library in Minecraft. Its continued learning occurs in code and context rather than continuous base-model weight updates.

Research problem

Open-ended exploration requires selecting useful next goals and reusing prior solutions instead of repeatedly generating low-level behavior from scratch.

How the mechanism works

  1. A curriculum proposes goals from current inventory, position, completed tasks and available abilities.
  2. The model generates programs, reads execution errors, environment feedback and task checks, then revises the program.
  3. Checked programs receive descriptions and embeddings in a skill library; later goals retrieve and compose relevant skills.

Study setting and reported evidence

Open exploration, technology-tree tasks and skill reuse in new worlds are compared with adapted agent baselines and component ablations. Metrics include unique items, distance, milestones and prompt rounds.

Limits and interpretation

The high-level game API already abstracts difficult control. Results do not establish general robotics capability. Incorrect success checks can contaminate the reusable skill library.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Store independently tested parsers and conversion workflows as versioned skills. Bind each skill to input types, software versions and acceptance tests; successful reuse on old structures does not validate new data automatically.

Reproduction and implementation checks

Match API access and model budgets across baselines. Record curriculum proposals, code attempts and skill-registration checks. Separate high-level API performance from pixel-input or low-level control systems.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.
