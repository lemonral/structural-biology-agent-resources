IPIGuard

IPIGuard: A Novel Tool Dependency Graph-Based Defense Against Indirect Prompt Injection in LLM Agents

First public: 2025-08-21 · Conference publication · EMNLP 2025 · Main conference

IPIGuard constrains execution to traversal of a dependency graph planned from trusted context. It also addresses unknown parameters and overlap between legitimate tools and malicious instructions, balancing defense with normal utility.

Research problem

Untrusted tool responses can redirect later actions even when those responses are necessary to complete a legitimate task.

How the mechanism works

  1. Before reading untrusted returns, build a dependency plan from the user instruction, tool descriptions and designated trusted materials.
  2. Distinguish determined nodes from parameters requiring observations; permit constrained query-driven expansion rather than arbitrary new actions.
  3. Use controlled simulated-call feedback for selected parameter-contamination cases, avoiding actual execution of the induced action.

Study setting and reported evidence

AgentDojo experiments compare attacks, models and defenses using unattacked utility, attacked utility, attack success, tokens and time. Ablations investigate simulation and planner choices within the tested conditions.

Limits and interpretation

A mistaken initial plan can either block useful work or leave excess authority. Defensive simulated feedback is not real-world state and must not contaminate scientific evidence.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Keep operation and resource authority in the executor; papers, logs and database returns supply data only. Permit justified replanning, while recording defensive simulation separately from measurements and real artifacts.

Reproduction and implementation checks

Freeze trust boundaries, dependency plans, attacker access and budgets. Report normal-task degradation alongside attack reduction and inspect where simulated returns enter subsequent context.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.

Evaluation foundation

R019 · AgentDojo

AgentDojo evaluates indirect prompt-injection attacks and defenses while measuring legitimate task utility. It separates untrusted tool content from the user's authorized objective.

R015 · LLMCompiler

LLMCompiler plans function calls as a dependency graph and executes ready tasks in parallel. The benefit targets unnecessary serialization and repeated planning, while preserving actual data dependencies.
