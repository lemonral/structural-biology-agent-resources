SpatialAgent

SpatialAgent: An Autonomous AI Agent for Spatial Biology

First public: 2025-04-06 · Preprint · bioRxiv · 2026-08-12 v2

SpatialAgent uses a Plan–Act–Conclude architecture for spatial biology, combining domain tools and multimodal interpretation. Tissue preparation and sequencing remain researcher activities.

Research problemMechanismEvidenceLimitsImplementationReproductionReading connectionsSources

Research problem

Spatial analysis must connect data processing, images and biological claims without allowing an unexecuted plan to become a scientific narrative.

How the mechanism works

  1. Plan around the research objective, execute tools or code, and ground conclusions in returned data and visual results.
  2. Retrieve domain databases, literature tools and skill templates with explicit input and version assumptions.
  3. Review claims against multimodal observations and sources, separating visual clarity from scientific support.

Study setting and reported evidence

The archived review records a v2 description involving multiple organ datasets and prospective spatial work, plus the authors' tool/skill README. Full v2 text was not directly obtained in that review, so baseline, budget and success-rate claims were not independently rechecked.

Source coverage: Original guide has limited source-version access. This English edition translates the archived review and does not claim a new independent reproduction.

Limits and interpretation

A repository demonstrates modules and entry points, not experimental superiority. Platform, tissue and annotation differences affect interpretation; an image-based narrative is not independent mechanistic evidence.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Bind visualized regions to the actual analysis selection so the user and agent refer to the same object. Structural pictures should link back to coordinates, maps and numerical evidence.

Reproduction and implementation checks

Start from the cited implementation and record its version. Treat the archived evidence boundary explicitly: inspect the full paper before making quantitative comparisons, and separate human experiments from computational assistance.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.
