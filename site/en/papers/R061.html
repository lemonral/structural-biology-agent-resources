AgentFold: Closed-Loop Agentic Search for Protein Folding Model Design

First public: 2026-08-27 · Preprint · arXiv · 2026-08-27 · v2 2026-08-28

AgentFold frames folding-model development as hypothesis generation, code modification, training/evaluation and experience retention. It changes a predictor itself rather than supplying a general assistant for arbitrary structural files.

Research problem

Model-development search must compare executable experiments while using failures and successful modifications without repeatedly proposing the same direction.

How the mechanism works

  1. Store concrete code snapshots in a search tree, selecting parents using performance and search utility while retaining diverse references.
  2. Coordinate deduplication, planning/coding and runtime debugging; a patch counts only when it enters real training and evaluation.
  3. Save diffs, configuration, stability and metric changes, then summarize parent-specific lessons without hiding individual structural metrics behind one score.

Study setting and reported evidence

CAMEO2022 development evaluation matches 36 evaluations across integrated search, independent proposals and a random controller. Best/Top-5 lDDT and a composite score improve in the reported protocol, but not every global metric improves uniformly.

Limits and interpretation

Repeated selection on a development benchmark can overfit it. Historical associations between edits and success do not establish universal causal improvement.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Separate routine structural-tool execution from a model-development laboratory. Reuse code lineage and budget-matched experiments, but do not call development-set search performance general agent task-completion ability.

Reproduction and implementation checks

Freeze final code before evaluating later independent targets. Preserve all candidate runs, costs, failed training and decomposed metrics rather than only the best snapshot.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.
