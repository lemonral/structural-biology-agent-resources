ReTool

ReTool: Reinforcement Learning for Strategic Tool Use in LLMs

First public: 2025-04-15 · Conference publication · ICLR 2026 · Main conference

ReTool combines natural-language reasoning and live code execution during training, using a code-enhanced cold start and outcome reinforcement learning. The objective is to learn when and how to use feedback, beyond granting interpreter access.

Research problemMechanismEvidenceLimitsImplementationReproductionReading connectionsSources

Research problem

A model may know how to emit code yet fail to choose useful calculation moments or recover from real execution errors.

How the mechanism works

  1. Use executable reasoning examples to establish basic interaction syntax during cold start.
  2. Run code during multi-turn rollouts and feed actual results or errors into the same reasoning trajectory.
  3. Optimize outcome rewards and ablate reinforcement learning, interpreter access and initialization to identify their contributions.

Study setting and reported evidence

Qwen2.5-32B experiments include AIME 2024/2025 and ablations; removing RL or the interpreter degrades performance. The formal manuscript also explores Bing search on GAIA and BrowseComp-ZH under stated settings.

Limits and interpretation

Final-answer rewards do not guarantee sound assumptions or efficient calls. Live execution adds environment cost, and fewer training steps do not necessarily mean lower total cost.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Study tool timing and repair first on geometric tasks with exact reference values. Mathematical answer rewards should not be transplanted to long simulations without object, unit and independent numerical checks.

Reproduction and implementation checks

Match cold starts and backbone models in text/tool comparisons. Track real execution cost, erroneous programs, corrections and total training budget separately from final benchmark accuracy.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.
