R019 · Evaluation, security and research maps

AgentDojo

AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents

First public: 2024-06-19 · Conference publication · NeurIPS 2024 · Datasets & Benchmarks

AgentDojo evaluates indirect prompt-injection attacks and defenses while measuring legitimate task utility. It separates untrusted tool content from the user's authorized objective.

Research problemMechanismEvidenceLimitsImplementationReproductionReading connectionsSources

Research problem

A defense can appear safe by preventing all useful work. Evaluation must distinguish ordinary task failure, attack success and utility lost to the defense.

How the mechanism works

  1. Define legitimate tasks and executable environment state, and establish performance without attacks.
  2. Replace controlled portions of tool-returned data with attacker-controlled content while keeping attacker and user goals separate.
  3. Evaluate task completion and violated security objectives jointly across models, attacks and defenses.

Study setting and reported evidence

The official NeurIPS 2024 abstract describes 97 tasks and 629 security tests. Even strong models fail some unattacked tasks, and tested attacks violate some, rather than all, security properties.

Source coverage: Original guide uses an official abstract and prior source notes. This English edition translates the archived review and does not claim a new independent reproduction.

Limits and interpretation

Controlled transactional environments do not cover every production identity, authorization or data-flow issue. Attack access, feedback and budget materially affect the outcome.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Treat papers, software documentation and tool logs as sourced data that cannot redefine permissions. Pair scientific workflows with attack cases; refusing every computation is not useful security success.

Reproduction and implementation checks

Specify attacker capabilities and injection boundaries, freeze environments and compare attacked with unattacked utility. Report legitimate completion and security violations separately instead of collapsing them into one score.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.

Compare mechanisms

R037 · IPIGuard

IPIGuard constrains execution to traversal of a dependency graph planned from trusted context. It also addresses unknown parameters and overlap between legitimate tools and malicious instructions, balancing defense with normal utility.

Complementary perspective

R077 · Tau Bench

Tau-bench evaluates tools, user dialogue and domain policies in a mutable environment, checking final database state. Its pass^k measures success on every repeated run, unlike pass@k's at-least-one success.
