Tau2 Bench

τ²-Bench: Evaluating Conversational Agents in a Dual-Control Environment

First public: 2025-06-09 · Conference publication · ICML 2026 · Main conference

Tau-squared Bench models both the user and agent as tool-using participants who can change a shared world. Success requires communication and coordination across control boundaries, beyond the agent's own database actions.

Research problemMechanismEvidenceLimitsImplementationReproductionReading connectionsSources

Research problem

A conversational assistant may need a user to change a device or supply state while the assistant performs complementary operations.

How the mechanism works

  1. Give both sides state-changing tools so user statements are constrained by executable environmental state.
  2. Compose scenarios from atomic faults and solution actions, with policies and completion conditions independent of dialogue fluency.
  3. Use No-User and other ablations and repeated runs to separate coordination difficulty from occasional task success.

Study setting and reported evidence

Retail, airline and telecom tasks include user-side device tools in telecom. Task success and pass^k reveal reliability difficulties; within-domain ablations help isolate the cost of communication and divided state.

Limits and interpretation

The user is still model-simulated, with assumptions about language and cooperation. Differences across domains also reflect tools, policies and task complexity, not only dual control.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Version a researcher's file, chain and residue selections as shared state. If the user changes an object while computation waits, reconcile affected plans rather than overwriting new selections with stale results.

Reproduction and implementation checks

Fix user simulation, policies, starting state and tool access. Report repeated-run reliability and same-domain ablations, while scoring conversational coordination separately from scientific calculations.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.

Explicit extension

R077 · Tau Bench

Tau-bench evaluates tools, user dialogue and domain policies in a mutable environment, checking final database state. Its pass^k measures success on every repeated run, unlike pass@k's at-least-one success.

Compare mechanisms

R078 · ToolSandbox

ToolSandbox evaluates multi-turn tool use using explicit world state, simulated users, milestones and forbidden events. Its evaluation DAG allows valid ordering alternatives rather than forcing one execution workflow.
