R020 · Learning, memory and system optimization

ADAS

Automated Design of Agentic Systems

First public: 2024-08-15 · Conference publication · ICLR 2025 · Main conference

ADAS represents agents as programs and uses a meta-agent to propose, evaluate and archive new system designs. Meta Agent Search explores prompts, control flow and module composition rather than optimizing one fixed prompt.

Research problemMechanismEvidenceLimitsImplementationReproductionReading connectionsSources

Research problem

Manual agent architectures constrain the design space; automated search needs an expressive representation and reliable feedback on generated candidates.

How the mechanism works

  1. Represent model calls, control logic and result integration in executable programs with a common model interface.
  2. Let a meta-agent read an archive of prior designs, scores and feedback before proposing a distinct candidate.
  3. Execute candidates on development data, update the archive and evaluate selected designs on independent tests and transfer tasks.

Study setting and reported evidence

Experiments include a small-grid ARC subset and coding, scientific and mathematical tasks, with some cross-model and cross-domain transfer. The reported findings concern these tested subsets, not a solution to full ARC.

Limits and interpretation

Repeated evaluations adapt designs to the development distribution. An expressive programming language does not make its entire program space searchable within a finite budget.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Search scientific-agent architectures only after trustworthy tasks and validators exist. Hold permissions, object constraints and budgets fixed, then independently test selected systems on new structures and combinations.

Reproduction and implementation checks

Track every candidate's construction and execution cost, retain the archive and isolate final tests. Compare searched designs with manually designed agents under stated search budgets.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.
