R013 · Reasoning, action and orchestration

LATS

Language Agent Tree Search Unifies Reasoning, Acting, and Planning in Language Models

First public: 2023-10-06 · Conference publication · ICML 2024 · Main conference

LATS combines candidate generation, external actions, reflection and Monte Carlo tree search. It allocates additional inference computation across alternative trajectories without training model weights.

Research problemMechanismEvidenceLimitsImplementationReproductionReading connectionsSources

Research problem

A single generated path can commit too early to a bad plan. Search offers alternatives when intermediate or terminal feedback can distinguish useful branches.

How the mechanism works

  1. Represent partial reasoning and action histories as tree nodes and generate multiple candidate continuations.
  2. Use UCT selection, model value judgments and repeated-action consistency as search heuristics; terminal feedback updates path values.
  3. Execute actions or programs, incorporate observations and reflect on failed branches before expanding later candidates.

Study setting and reported evidence

The HotpotQA experiment uses a 100-question subset and an answer-correctness oracle after submission. Coding experiments search with synthetic tests, then score the selected program on real tests. Final pass@1 therefore follows multi-candidate search.

Limits and interpretation

Open scientific questions rarely provide an immediate correctness oracle. Model-generated candidates and model-based values can reinforce shared errors; expensive simulations limit branching.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Use bounded search for inexpensive, isolated analysis candidates. Check proxies before expensive computation, then validate independently. Scientific jobs with side effects should not be treated as freely reversible search branches.

Reproduction and implementation checks

Log expansion width, iterations, all candidate costs and the feedback available at each step. Distinguish search-time synthetic tests or oracle feedback from final held-out acceptance.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.

Compare mechanisms

ReAct interleaves language-based decisions with external actions and observations. New observations can change the next step, but this loop alone does not supply permissions, durable recovery or scientific acceptance rules.

R021 · AFlow

AFlow searches reusable code-defined agent workflows with execution feedback. A search node is a complete workflow selected during development, rather than a per-question action state explored anew at deployment.
