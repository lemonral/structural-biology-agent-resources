R017 · Scientific systems and structural biology

CellAgent

CellAgent: LLM-Driven Multi-Agent Framework for Natural Language-Based Single-Cell Analysis

First public: 2024-05-15 · Conference publication · ICLR 2026 · Main conference

CellAgent joins planning, execution and evaluation for single-cell and spatial data, with domain tools organized through sc-Omni. The contribution is a domain workflow with computable feedback, beyond generic code generation.

Research problem

Natural-language analysis must select methods suitable for data characteristics and check whether the resulting biological analysis satisfies the user's goal.

How the mechanism works

  1. Diagnose the task using both user intent and data state, then decompose it into coherent subtasks.
  2. Retrieve expert-curated tools and execute analysis in the relevant environment, returning actual code and execution errors.
  3. Evaluate task-specific outputs and adjust selected methods or parameters rather than accepting a clean plot or successful process exit.

Study setting and reported evidence

The locally archived 2025 manuscript covers single-cell and spatial tasks, several datasets and comparisons with analytical or human workflows. It reports efficiency gains and comparable quality in some tasks; metrics remain task-specific.

Source coverage: Original guide has limited source-version access. This English edition translates the archived review and does not claim a new independent reproduction.

Limits and interpretation

Clustering or integration proxies can improve while rare populations or genuine biology are lost. Input conventions, reference annotations and evaluators are part of the capability, not incidental setup.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Adopt domain toolboxes with dedicated validators for structural comparison, map fitting and dynamics. Before feedback changes a plan, verify that the metric measures the scientific objective rather than an easy proxy.

Reproduction and implementation checks

Record manuscript and software versions separately from the later conference identity. Freeze datasets, annotation references and metrics; report quality and human effort independently rather than one combined correctness score.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.
