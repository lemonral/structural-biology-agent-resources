English reading guides for agent foundations, learning and memory, scientific systems, structural biology, evaluation and security.

These are standalone editorial translations of the archived research notes, with compact mechanism, evidence, limitation and implementation sections. They are not line-by-line translations or independent reproductions. The English guides retain source-access limitations and distinguish the paper's results from our design inferences.

A reading route

  1. Start with CoT, ReAct and the difference between a generated plan and actual execution.
  2. Compare graph scheduling, search, episodic memory, offline program optimization and role coordination.
  3. Inspect scientific systems for tools, data, researcher participation and the exact evidence produced.
  4. Choose benchmarks that separate interface validity, workflow completion, scientific output, robustness and full-project success.

How decisions become actions and observations.

R001 · 2022-01-28

CoT

Chain-of-thought (CoT) prompting places a question, intermediate natural-language steps and an answer in each few-shot demonstration. It studies reasoning prompts rather than an agent that executes tools.

R002 · 2022-10-06

ReAct

ReAct interleaves language-based decisions with external actions and observations. New observations can change the next step, but this loop alone does not supply permissions, durable recovery or scientific acceptance rules.
