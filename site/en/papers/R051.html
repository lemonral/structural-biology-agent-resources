R051 · Scientific systems and structural biology

Agentomics

Agentomics: an agentic system that autonomously develops novel state-of-the-art solutions for biomedical machine learning tasks

First public: 2026-01-30 · Journal publication · Bioinformatics · 2026-07-07

Agentomics decomposes biomedical supervised learning into validated stages and iteratively selects modeling strategies on validation data. Outputs include models, scripts, environments and reports, not new biological-mechanism discoveries by default.

Research problem

Automated modeling must maintain valid splits and reproducible artifacts across many iterations without exposing the test set to model selection.

How the mechanism works

  1. Use fresh stage contexts for exploration, splitting, representation, architecture and implementation, passing structured results through a shared workspace.
  2. Require JSON and functional checks, such as file existence and split non-overlap, before advancing; return failures for bounded revision or restart.
  3. Design new experiments from previous summaries, retain the best complete validation iteration and score hidden tests programmatically.

Study setting and reported evidence

Twenty biomedical datasets use three eight-hour runs with specified hardware. Reported best-of-three results exceed compared human-best scores on 11 datasets, while 19 of 60 individual runs do so. Selection rules materially affect interpretation.

Source coverage: Original guide uses an official abstract and prior source notes. This English edition translates the archived review and does not claim a new independent reproduction.

Limits and interpretation

Best-repeat performance differs from first-run reliability. Non-overlapping samples do not eliminate related-object leakage, pretraining overlap or distribution shifts, and repeated validation search may overfit.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Adopt stage artifacts and hidden-test isolation for structural prediction workflows, splitting with object similarity in mind. Keep every experiment and failure budget, not only the selected model.

Reproduction and implementation checks

Report all repeats, resource limits, validation selection and independent test outcomes. Inspect weak runs and temporal validation/test divergence instead of treating high correlation as proof of no overfitting.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.
