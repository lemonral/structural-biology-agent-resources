R004 · Reasoning, action and orchestration

Reflexion

Reflexion: Language Agents with Verbal Reinforcement Learning

First public: 2023-03-20 · Conference publication · NeurIPS 2023 · Main Track

Reflexion compresses task feedback into verbal reflections that persist across attempts. Improvement occurs through episodic context and additional attempts, without updating the base model's weights.

Research problemMechanismEvidenceLimitsImplementationReproductionReading connectionsSources

Research problem

A failure signal alone may not prevent the next attempt from repeating the same mistake. Black-box models also make conventional gradient-based reinforcement learning inconvenient.

How the mechanism works

  1. An actor reads the task and previous reflections, then produces an action trajectory or program.
  2. An evaluator supplies success signals or textual feedback. Generated tests, model assessments and external hidden tests have different evidential strength.
  3. A reflection module summarizes actionable lessons into a bounded memory buffer for the next attempt; within-attempt observations and cross-attempt memory remain distinct.

Study setting and reported evidence

The paper studies sequential decision, reasoning and coding tasks. HumanEval and other settings improve, but MBPP Python is below the base result; inadequate or misleading generated tests can lead to premature acceptance.

Limits and interpretation

Incorrect feedback can turn a wrong explanation into persistent experience. Final success after several attempts cannot be compared with raw pass@1 while ignoring the accumulated budget.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Promote only independently checked failures, such as parsing or mapping errors, into reusable scientific experience. Retain input conditions, software version and counterexamples for each lesson.

Reproduction and implementation checks

Track per-attempt and total cost separately. Fix evaluator, tests and memory capacity; compare retries with and without reflection. Inspect false-positive generated tests and the resulting stopping decisions.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.
