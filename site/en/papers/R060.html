Agent Lightning 1

Agent Lightning v1.0: Towards Harnessed Agentic RL

First public: 2026-08-18 · Preprint · arXiv · 2026

Agent Lightning v1.0 keeps the deployment harness responsible for tools and context while attaching training through the model interface. It examines how dynamic real call traces become statistically appropriate reinforcement-learning samples.

Research problem

Summaries, branches and subagents make actual request histories differ from a single ever-growing chat sequence, complicating sample construction and reward attribution.

How the mechanism works

  1. Record real model requests and responses while the existing harness retains tool, environment and context management.
  2. Merge adjacent calls only when their actual tokens satisfy prefix conditions; otherwise begin a new sample while preserving rollout and prompt-group identity.
  3. Handle dynamic sample counts and distinguish token-, sequence- and rollout-normalization choices so physical trace splitting does not silently reweight tasks.

Study setting and reported evidence

Instruction-following, search and coding experiments include a reported SWE-bench Verified improvement for the same backbone under the supplied data, harness, reward and budget. This is not a controlled victory over every training framework.

Limits and interpretation

Easy interface attachment still requires trainable weights, complete traces, environment resources and trustworthy rewards. Harness changes alter the distribution and may invalidate previous training results.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Establish stable structural execution, traceable calls and independent scientific rewards before training on real workflows. Rewarding process exit alone can reinforce scientifically wrong outputs.

Reproduction and implementation checks

Pin harness and model versions together, retain token boundaries and sample/rollout ownership, and verify normalization choices. Separate rollout collection correctness from the validity of the scientific reward.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.
