R044 · Learning, memory and system optimization

ACE

Agentic Context Engineering: Evolving Contexts for Self-Improving Language Models

First public: 2025-10-06 · Conference publication · ICLR 2026 · Main conference

ACE maintains context as an evolving playbook through generation, reflection and curation. It changes input context rather than model weights and avoids information loss from repeatedly rewriting an entire prompt.

Research problemMechanismEvidenceLimitsImplementationReproductionReading connectionsSources

Research problem

Growing experience can collapse into vague summaries or overwrite useful details unless updates are attributable and incremental.

How the mechanism works

  1. Generator uses identified playbook entries and records helpful or misleading feedback against their individual counters.
  2. Reflector extracts lessons; Curator proposes incremental entries that deterministic logic merges with the existing playbook.
  3. Grow and refine by appending, updating and semantically deduplicating entries, supporting offline passes and online adaptation.

Study setting and reported evidence

AppWorld compares offline/online adaptation with ReAct and context-optimization baselines. Financial tasks include labeled and unlabeled feedback; unlabeled online ACE underperforms the base model on FiNER, demonstrating context contamination risk.

Limits and interpretation

Helpful counts and reflections are not independent fact checks. Online results depend on task ordering, previous test experience and, in some settings, offline warm-up.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Record verified software limitations, input preconditions and repair rules with tool versions. Admit experience to a long-term scientific playbook only after independent artifact checks.

Reproduction and implementation checks

Preserve sample order, warm-up and whether reflectors see labels. Compare identical adaptation protocols, inspect misleading entries and distinguish larger context from improved scientific explanations.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.

Compare mechanisms

R004 · Reflexion

Reflexion compresses task feedback into verbal reflections that persist across attempts. Improvement occurs through episodic context and additional attempts, without updating the base model's weights.

Compare mechanisms

R048 · MemRL

MemRL learns utility values for external episodic memories while freezing the language model. Runtime reinforcement learning updates memory scores and retrieval order, not base-model weights.
