R043 · Scientific systems and structural biology

Speak to a Protein

Speak to a Protein: An Interactive Multimodal Co-Scientist for Protein Analysis

First public: 2025-10-01 · Journal publication · Journal of Chemical Information and Modeling · 2026-10-12

Speak to a Protein joins retrieval, code execution and an observable three-dimensional scene in one conversational analysis environment. Current viewer state is returned to the agent rather than inferred from chat history.

Research problem

A researcher and agent can otherwise discuss different structures or selections while appearing to share the same visual context.

How the mechanism works

  1. An agent shell dispatches tools into an isolated workspace with scientific software and persistent files, retaining execution records beneath compressed working memory.
  2. Viewer tools load structures, control displays and capture scenes; each user message includes current objects, visibility, selections and a screenshot.
  3. Load detailed skill instructions on demand and combine literature/document retrieval with executable analysis and report artifacts.

Study setting and reported evidence

BixBench-Verified-50 and structural cases assess the system. A separate 50-task protein-analysis set, with three seeds and deterministic scoring, includes viewer and Bash-only ablations; viewer gains are concentrated in 3D reasoning.

Source coverage: Original guide checked against the full text. This English edition translates the archived review and does not claim a new independent reproduction.

Limits and interpretation

Cross-system leaderboard settings differ in model and configuration. Usage counts do not establish scientific correctness, and public reproduction code is not necessarily a complete offline hosted backend.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Version structural objects, chains, residues and display selections and bind each action to that version. Use screenshots for observation but recompute key geometry from coordinates, tracking front-end/server file synchronization.

Reproduction and implementation checks

Pin task subsets, models, viewers and execution locations. Separate browser Python from server state, compare only genuinely comparable task categories and retain original artifacts under summaries.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.

State observability

R032 · ScienceBoard

ScienceBoard places agents in virtual machines running real scientific applications and checks internal software state. It combines visual interaction, commands and scientific workflows, while distinguishing task-state completion from scientific discovery.

Structural-tool integration

R053 · ProteinMCP

ProteinMCP connects protein-computing software through MCP services and workflow skills. Its case studies mainly demonstrate executable computational integration rather than new experimental affinity or function.
