R048 · Learning, memory and system optimization

MemRL

MemRL: Self-Evolving Agents via Runtime Reinforcement Learning on Episodic Memory

First public: 2026-01-06 · Preprint · arXiv · 2026

MemRL learns utility values for external episodic memories while freezing the language model. Runtime reinforcement learning updates memory scores and retrieval order, not base-model weights.

Research problemMechanismEvidenceLimitsImplementationReproductionReading connectionsSources

Research problem

Semantic similarity alone may retrieve experiences that look relevant but have not been useful for solving the current kind of task.

How the mechanism works

  1. Store intent representations, trajectories or summaries and utility Q-values as distinct fields.
  2. Recall semantically eligible candidates, then rank with normalized similarity and utility; if no candidate qualifies, let the frozen model explore.
  3. After execution, update injected memories from outcome rewards and optionally summarize the new experience into the library.

Study setting and reported evidence

HLE, BigCodeBench, ALFWorld and Lifelong Agent Bench run across ten rounds. Final-round success and cumulative success across attempts differ. Cross-task retrieval helps some environments but not uniformly, including a non-improvement in HLE.

Limits and interpretation

A shared outcome update does not isolate each memory's causal value. Stability arguments assume a frozen inference policy and sufficiently stable distributions.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Retrieve conditional lessons about recurring structural-software failures using data type and tool version. Rewards must come from independent artifacts, and utility needs revalidation after software or task-distribution changes.

Reproduction and implementation checks

Record memory eligibility, injected entries, reward updates and task order. Evaluate fixed-memory held-out transfer separately from cumulative repeated-attempt gains and compare similarity-only retrieval.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.
