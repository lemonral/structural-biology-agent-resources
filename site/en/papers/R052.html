SciAgentGym

SciAgentGym: Benchmarking Multi-Step Scientific Tool-Use in LLM Agents

First public: 2026-02-13 · Conference publication · ICML 2026 · Main conference

SciAgentGym supplies a stateful scientific-tool environment, SciAgentBench evaluates multi-step tasks, and SciForge synthesizes executable training trajectories. These are distinct environment, benchmark and data contributions.

Research problem

Tool access alone does not establish that an agent can compose long scientific workflows or recover from intermediate errors.

How the mechanism works

  1. Declare input/output types and exchange serialized scientific objects in isolated workspaces with read-only task assets and structured errors.
  2. Filter and expert-review tasks with executable reference trajectories; measure all-subquestion success and path-length-adjusted efficiency separately.
  3. Build typed dependency graphs, bind parameters and execute sampled paths; retain recoverable failures before generating questions from verified trajectories.

Study setting and reported evidence

Within-model tool/no-tool comparisons show gains for some models but not all, with harder multi-step tasks remaining difficult. SFT comparisons find relevant scientific trajectories with error recovery more useful than clean-only or unrelated tool data.

Limits and interpretation

Type compatibility is not compatibility of units, coordinate frames or physical objects. Difficulty filters and feasible reference paths constrain coverage; a large tool count is not structural-biology coverage.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Extend tool contracts with structural identities, units and frames. Train and evaluate complete tasks with explainable failure branches, allowing valid alternative scientific routes rather than requiring one exact reference sequence.

Reproduction and implementation checks

Version environments, task filters, reference paths and training traces. Report success and efficiency separately and test whether errors originate in the tool environment or the controller.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.

R050 · BioAgent Bench

BioAgent Bench evaluates bioinformatics workflows through explicit inputs, required steps and output files, adding corruption, distractor and prompt-bloating tests. Workflow completion is necessary but insufficient for scientific reliability.
