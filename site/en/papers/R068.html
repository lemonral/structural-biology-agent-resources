R068 · Evaluation, security and research maps

Agent Survey

A Survey on Large Language Model based Autonomous Agents

First public: Not recorded in source index · Journal publication · Frontiers of Computer Science · 2025

This survey organizes autonomous language agents around construction, applications and evaluation, using profiling, memory, planning and action as a conceptual architecture map. It does not experimentally identify a best architecture.

Research problem

Papers often reuse the same labels for different state representations, feedback mechanisms or training assumptions, making superficial comparisons misleading.

How the mechanism works

  1. Locate contributions within profiling, memory, planning and action rather than treating each whole system as incomparable.
  2. Further distinguish memory structures/formats/read-write operations, feedback-based planning, and action goals, spaces and effects.
  3. Cross-reference capability acquisition with or without fine-tuning, application domains and subjective or objective evaluation.

Study setting and reported evidence

The evidence is a structured synthesis of representative literature and concepts, not shared-data/model/budget performance testing. Completeness of four named modules is not established as necessary or sufficient for success.

Source coverage: Original guide checked against the full text. This English edition translates the archived review and does not claim a new independent reproduction.

Limits and interpretation

Categories overlap: reflection can affect both memory and planning. Cross-paper results cannot isolate component causality, and a figure's historical cutoff should not be mistaken for the coverage of an updated manuscript.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Use the four-part map to check information flow in a structural-agent proposal, then add scientific objects, persistent jobs and validation contracts at implementation level.

Reproduction and implementation checks

Follow representative references and record manuscript version and coverage. Compare actual state updates, tools and evaluators rather than inferring equivalence from shared module names.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.

Framework and implementation

R002 · ReAct

ReAct interleaves language-based decisions with external actions and observations. New observations can change the next step, but this loop alone does not supply permissions, durable recovery or scientific acceptance rules.
