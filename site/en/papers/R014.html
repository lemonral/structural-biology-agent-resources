MemGPT

MemGPT: Towards LLMs as Operating Systems

First public: 2023-10-12 · Preprint · arXiv · 2023/2024 v2

MemGPT uses storage hierarchies and paging-like operations to manage a finite model context with external memory. It increases accessible information rather than changing the Transformer's actual context-window size.

Research problem

Multi-session conversations and document analysis require relevant historical information that cannot all remain visible in the prompt.

How the mechanism works

  1. Separate the visible working context, retrievable history and long-term archive while retaining essential instructions.
  2. Expose search, read, write and context-editing functions so the model can retrieve information and maintain compact memory.
  3. Use events, capacity warnings and continuation controls to permit memory operations before producing a user-facing response.

Study setting and reported evidence

Multi-session deep-memory retrieval, conversation openings and document tasks compare fixed-context baselines with memory-enabled configurations. Measures include historical QA accuracy, ROUGE-L and information similarity.

Limits and interpretation

Retrievability does not establish truth, freshness or conflict resolution. Function-use failures can make large external storage ineffective while adding latency and cost.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Manage current task summaries, reusable experience and original structural files separately. Context should contain necessary references and decisions; memory needs provenance and versions and must not replace the job-state ledger.

Reproduction and implementation checks

Reconstruct storage tiers, memory functions and retention policy. Test cross-session retrieval, conflicting updates and missing memories, and report additional calls rather than only final answer quality.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.
