R070 · Scientific systems and structural biology

ChemCrow

ChemCrow: Augmenting large-language models with chemistry tools

First public: Not recorded in source index · See publication record · See publication record

ChemCrow connects chemistry tools to a reasoning–action–observation loop. Its comparison between expert and model evaluation shows that fluent scientific narratives can still yield incorrect results.

Research problemMechanismEvidenceLimitsImplementationReproductionReading connectionsSources

Research problem

General language models lack reliable execution and specialist calculations, while automated judges may fail to distinguish convincing prose from scientifically supported answers.

How the mechanism works

  1. Expose domain tools with natural-language capability descriptions and input interfaces; the archived v5 lists eighteen tools, distinct from earlier inventories.
  2. Pause model generation for real calls and return observations before deciding the next action or response.
  3. Evaluate task handling, reasoning and chemical correctness with domain experts as well as an LLM judge.

Study setting and reported evidence

Fourteen use cases compare ChemCrow with tool-free GPT-4. Expert judgments support the tool-enabled system in these settings, whereas model judging misses some clear errors. Selected external experiments provide case-specific evidence with specialist platforms and human participation.

Source coverage: Original guide checked against the full text. This English edition translates the archived review and does not claim a new independent reproduction.

Limits and interpretation

Prepared examples do not estimate success across all unknown chemistry tasks. Wrong tool inputs or outputs can propagate, and automatic judgments need task-specific calibration.

Implications for a structural-biology agent

Editorial design inference, distinct from the paper's measured result.

Retain auditable numerical observations and evaluate structural outputs against geometry, experimental consistency or expert criteria. A conversational rationale helps trace decisions but cannot certify its own scientific correctness.

Reproduction and implementation checks

Pin tool inventory and model versions and record execution conditions. Reassess judge agreement with experts, keeping experimental case validation separate from the overall tool-use score.

Reading connections

Use the paired mechanisms to locate what changes between systems: information access, control, memory, training, execution or acceptance.

Mechanism used by this work

R002 · ReAct

ReAct interleaves language-based decisions with external actions and observations. New observations can change the next step, but this loop alone does not supply permissions, durable recovery or scientific acceptance rules.

Compare scoring dimensions

R062 · BIABench

BIABench reconstructs end-to-end analysis from raw biological images and published scientific results. It scores final artifacts separately from the narrated process to test whether agents compute correct results consistently.
