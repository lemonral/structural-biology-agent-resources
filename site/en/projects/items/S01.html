Biomni

Combine scientific tools, packages and databases with planning and code execution.

Scientific agent and research environment

Source snapshot: 2026-10-30 · Chinese original

1. Position in the system

Biomni illustrates a unified environment of scientific functions, packages, databases and agent code execution. Tool counts do not establish that every listed capability has been validated.

Best fit
Studying how a scientific software/data environment supports agent-composed analysis.
Boundary
Environment coverage does not establish scientific validity for every structural, density-map or trajectory task.
Relation to other systems
Evaluate environment coverage, planning/execution and scientific inference as separate system layers.

2. Mechanism at a glance

  1. Select tools and data resources
  2. Plan and execute code
  3. Analyze observations and produce results

Components and responsibilities

ComponentResponsibility
Tools and environment catalogueScientific functions and dependencies provide actions. Tool metadata, library versions and data paths determine reproducibility.
A1 and run stateA1 connects models, tasks and environments, with objects such as AgentState organizing analysis. Trace model selection, real execution and actual returns separately.
Configuration and resultsModels, timeouts, data and connections shape the run. Code, files and explanations require separate evaluation of program completion and scientific support.

3. Follow a real run

  1. Provide a research objective and relevant data.
  2. Select capabilities and generate a plan or analysis code.
  3. Execute in the environment and return observations, logs and files.
  4. Interpret results and independently check statistical, domain and evidence conditions.

State and recovery

Version tool catalogues, data environments, analysis code and artifacts together. Preserve model notes separately from tool observations; successful execution is not proof of discovery.

Deployment and dependencies

Model services, data downloads and scientific packages can introduce substantial dependencies. Start with one lightweight task and add required components. Distinguish preprint and later published evidence.

4. Tradeoffs and scientific use

A unified environment enables composition, while dependency management and validation coverage dominate the cost. Existing cases do not demonstrate every structural task.

Structural-biology adaptation

Trace a read-only structural-information analysis using typed tools, explicit file versions and independent acceptance.

Practice task

Trace a read-only structural-information task end to end, list actual tools and versions, then repeat with a new input to test beyond the tutorial.
