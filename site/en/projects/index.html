Frameworks, applications and infrastructure

39 English guides connect system roles to implementation, state, deployment, tradeoffs and a concrete practice task.

20 frameworks, 14 application/scientific-integration systems and 5 infrastructure projects. Read by responsibility rather than treating all projects as competing agent frameworks.

English edition: 14 November 2026. Original source snapshot: 30 October 2026. Chinese original catalogue · Structured English data

A practical reading route

  1. Build a single tool loop with LangChain, PydanticAI, smolagents, Google ADK or OpenAI Agents SDK.
  2. Study LangGraph or an explicit workflow when branches, waiting and recovery matter.
  3. Add retrieval, memory or collaboration only where the task requires it, and compare the added cost.
  4. Keep scientific tools, data contracts, external job scheduling and independent acceptance explicit.
  5. Use infrastructure such as MCP, Pydantic, tracing or durable workflows for their specific roles.

Role and deployment descriptions translate the original notes. The projects were not all installed, load tested or scientifically benchmarked.
